你好，我是李威樵，畢業於文化大學生活應用科學系。在大學期間，我曾在統一星巴克工作三年，這段期間不僅讓我學習到了許多咖啡知識，更重要的是培養了我的團隊合作與溝通能力。

小學時便對美術有著強烈熱愛，大學時期開始接觸 3ds max，也因這個契機，我進入壹傳媒的資材中心工作三年。期間參與了動新聞、Next Media Animation、Tomo Toon 等專案，負責 3D Model 製作、Texture 繪製以及角色骨架綁定等核心工作。

其後，我加入中佑資訊有限公司，初期負責 3D Model 製作、Lighting 與 Render 後製調色。隨著專案需求轉變，我跨足使用 Spine 2D 製作動圖，並開始擔任遊戲設計師。為了更精確地滿足 RD 的製作需求，我主動學習 After Effects 剪輯遊戲預覽影片，大幅提升了跨部門的溝通效率。

近期因職涯規劃，我透過職訓局投入程式設計領域，學習了 Java 語言、SQL 資料庫、Spring Boot、HTML/CSS/JS 以及 Angular 等技術，期望將程式邏輯與多年的美術底蘊結合，發揮更大的跨領域價值。
